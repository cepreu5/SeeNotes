## 🚀 Как да Стартираш?

### Стъпка 1: Генерирай Template (5 минути)

```bash
1. Отвори index.html в браузър
2. Натисни F12 (Developer Tools)
3. Отиди в Console таба
4. Копирай целия код от kb-generator.js
5. Постави в конзолата и натисни Enter
6. JSON ще се копира автоматично в clipboard
7. Създай нов файл kb-template.json и го запази
```

### Стъпка 2: Попълни Template (2-3 часа)

Отвори `kb-template.json` и попълни празните полета:

```json
{
  "keywords": {
    "bg": ["дума1", "дума2", "синоним"],  // ← Попълни
    "en": ["word1", "word2", "synonym"]    // ← Попълни
  },
  "question": {
    "bg": "Как да направя X?",             // ← Попълни
    "en": "How to do X?"                   // ← Попълни
  },
  "answer": {
    "bg": "Отиди в Settings и...",         // ← Попълни
    "en": "Go to Settings and..."          // ← Попълни
  }
}
```

**Съвет:** Използвай `kb-example.json` за референция!

### Стъпка 3: Запази като kb-data.json

```bash
1. Прегледай попълнения template
2. Провери за грешки (JSON validator)
3. Запази като kb-data.json
4. Готов си за следващата фаза!
```

## ❓ Често Задавани Въпроси

**Q: Трябва ли да попълня всичко наведнъж?**  
A: Не! Започни с 10-15 най-важни настройки и добавяй постепенно.

**Q: Какво ако не знам как да формулирам отговора?**  
A: Виж `kb-example.json` за примери. Пиши просто и ясно.

**Q: Колко keywords трябва да има всеки запис?**  
A: Минимум 3-5, оптимално 5-10. Мисли как ТИ би попитал.

**Q: Може ли да редактирам KB след това?**  
A: Да! Просто редактирай `kb-data.json` и презареди.
