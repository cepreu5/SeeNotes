## 🔄 Работен Процес

### Фаза 1: Генериране на Knowledge Base ✅ (ТЕКУЩА)

1. **Изпълни `kb-generator.js`** в browser console
2. **Получи `kb-template.json`** с автоматично извлечени данни
3. **Попълни празните полета:**
   - Keywords (как потребителите биха попитали)
   - Questions (типични въпроси)
   - Answers (кратки, ясни отговори)
4. **Запази като `kb-data.json`**

### Фаза 2: Имплементация на Асистента (СЛЕДВАЩА)

1. **kb-matcher.js** - Интелигентен алгоритъм за търсене
2. **kb-ui.js** - Чат интерфейс
3. **kb-assistant.js** - Главна логика
4. **kb-assistant.css** - Визуален дизайн

### Фаза 3: Интеграция (ФИНАЛНА)

1. Добавяне в `index.html`
2. Тестване
3. Оптимизация

## 🧠 Как Работи Matching-ът?

### Scoring Система

```javascript
Потребител пита: "как да покажа датите"

1. Разделяне на думи: ["как", "да", "покажа", "датите"]

2. Търсене в keywords:
   - "дата" в keywords → +10 точки
   - "показване" частично съвпадение → +3 точки
   
3. Сортиране по score

4. Връщане на топ 3 резултата
```

### Пример

**Въпрос:** "как да отворя линк"

**Matching:**
```
1. one-tap-link-checkbox (score: 23)
   - "линк" → +10
   - "отваряне" → +10
   - "как" → +3
   
2. search-box (score: 3)
   - "как" → +3

→ Показва отговор за "One-Click Links"
```

## 💡 Интелигентни Функции

### 1. Контекстна Помощ
```javascript
// Ако отговорът споменава UI елемент
answer: "Отиди в Settings и маркирай..."
→ Highlight на Settings бутона
```

### 2. Предложения
```javascript
// При отваряне на асистента
Често задавани:
- Как да започна?
- Как да търся в бележките?
- Мога ли да работя offline?
```

### 3. Fuzzy Matching
```javascript
// Разбира грешки в правописа
"лінк" → "линк"
"настроики" → "настройки"
```

### 4. Многоезичност
```javascript
// Автоматично превключване според currentLang
if (currentLang === 'bg') {
  return answer.bg;
} else {
  return answer.en;
}
```

## 💬 Въпроси и Отговори

**Q: Колко време ще отнеме попълването на KB?**  
A: За основните настройки (20-30 записа) - около 2-3 часа. Можеш да го правиш постепенно.

**Q: Трябва ли да попълня всички полета наведнъж?**  
A: Не! Започни с най-важните настройки и добавяй постепенно.

**Q: Какво ако потребителят попита нещо, което няма в KB?**  
A: Асистентът ще каже "Не намерих отговор на този въпрос" и ще предложи свързани теми.

**Q: Може ли да се обновява KB без да се променя кода?**  
A: Да! Просто редактирай `kb-data.json` и презареди страницата.

**Q: Ще забави ли приложението?**  
A: Не. KB е малък JSON файл (~50-100KB) и matching-ът е много бърз (<10ms).
