## Обща архитектура

Интелигентното търсене използва **семантично търсене** базирано на embeddings (вектори), генерирани от ML модел. Вместо просто текстово съвпадение, то намира бележки, които са **смислово свързани** с заявката.

## Ключови компоненти

### 3. `hashEmbeddingSource(text)` — FNV-1a хеш

```javascript
function hashEmbeddingSource(text) {
    const source = String(text || '');
    let hash = 2166136261;
    for (let i = 0; i < source.length; i++) {
        hash ^= source.charCodeAt(i);
        hash = Math.imul(hash, 16777619);
    }
    return (hash >>> 0).toString(16);
}
```

**Цел:** Бърз хеш за определяне дали текстът на бележката се е променил. Ако хешът съвпада с предишния, не се генерира нов embedding — **оптимизация за избягване на излишни ML изчисления**.

### 4. `getIntelligentSearchExtractor()` — Зареждане на модела

```javascript
async function getIntelligentSearchExtractor() {
    if (!isIntelligentSearchEnabled()) return null;
    if (!intelligentSearchExtractorPromise) {
        intelligentSearchExtractorPromise = import(INTELLIGENT_SEARCH_MODULE_URL)
            .then(async ({ pipeline, env }) => {
                if (env) {
                    env.allowLocalModels = false;
                    env.useFp16 = false;
                }
                return pipeline('feature-extraction', INTELLIGENT_SEARCH_MODEL, {
                    quantized: false
                });
            })
            .catch(error => {
                intelligentSearchExtractorPromise = null;
                throw error;
            });
    }
    return intelligentSearchExtractorPromise;
}
```

**Поведение:**
- Lazy loading — моделът се зарежда само при първо използване
- Singleton pattern — повторни извиквания връщат същия promise
- При грешка нулира promise-а, позволявайки повторен опит
- `quantized: false` — използва пълния модел (по-точен, но по-голям)

### 5. `addEmbeddingToNote(note)` — Генериране на embedding за една бележка

```javascript
async function addEmbeddingToNote(note) {
    const dbNote = { ...note }; // Копие
    if (!isIntelligentSearchEnabled()) {
        delete dbNote.embedding;
        delete dbNote.embeddingSourceHash;
        return dbNote;
    }

    const noteText = dbNote.notetxt || dbNote.text || '';
    const sourceHash = hashEmbeddingSource(noteText);

    if (!String(noteText).trim()) {
        delete dbNote.embedding;
        delete dbNote.embeddingSourceHash;
        return dbNote;
    }

    // Ако хешът съвпада — няма промяна, не регенерираме
    if (dbNote.embeddingSourceHash === sourceHash && Array.isArray(dbNote.embedding)) {
        return dbNote;
    }

    try {
        const extractor = await getIntelligentSearchExtractor();
        if (extractor) {
            const output = await extractor(noteText, { pooling: 'mean', normalize: true });
            dbNote.embedding = Array.from(output.data);
            dbNote.embeddingSourceHash = sourceHash;
        }
    } catch (e) {
        delete dbNote.embedding;
        delete dbNote.embeddingSourceHash;
    }

    return dbNote;
}
```

**Логика:**
1. Създава копие (immutable подход)
2. Ако функцията е изключена — изтрива полетата
3. Ако текстът е празен — изтрива полетата
4. **Кеширане:** Ако хешът съвпада и вече има embedding — пропуска (O(1))
5. Генерира embedding с `mean pooling` и `normalization`
6. Запазва като `Array.from(output.data)` — масив от float числа

### 6. `prepareNoteForIndexedDb(note)` — Подготовка преди запис в DB

```javascript
async function prepareNoteForIndexedDb(note) {
    const dbNote = { ...note };
    if (!isIntelligentSearchEnabled()) return dbNote;

    const noteText = dbNote.notetxt || dbNote.text || '';
    const sourceHash = hashEmbeddingSource(noteText);
    
    if (!String(noteText).trim()) {
        delete dbNote.embedding;
        delete dbNote.embeddingSourceHash;
        return dbNote;
    }
    
    if (dbNote.embeddingSourceHash === sourceHash && Array.isArray(dbNote.embedding)) {
        return dbNote;
    }

    try {
        const extractor = await getIntelligentSearchExtractor();
        if (!extractor) return dbNote;
        const output = await extractor(noteText, { pooling: 'mean', normalize: true });
        dbNote.embedding = Array.from(output.data);
        dbNote.embeddingSourceHash = sourceHash;
    } catch (error) {
        console.warn('[IntelligentSearch] Failed to generate note embedding:', error);
    }
    return dbNote;
}
```

Практически идентична с `addEmbeddingToNote`, но **по-нежна при грешки** (warn вместо delete). Използва се при запазване на бележка в IndexedDB.

### 7. `indexNotesForIntelligentSearch()` — Масово индексиране

```javascript
async function indexNotesForIntelligentSearch() {
    if (!isIntelligentSearchEnabled()) return 0;

    try {
        // Зарежда модела ВЕДНЪЖ преди цикъла
        await getIntelligentSearchExtractor();
        const notes = await getAllFromDB(NOTE_STORE_NAME);
        let indexedCount = 0;
        let skippedCount = 0;

        for (const note of notes) {
            const noteText = note.notetxt || note.text || '';
            const sourceHash = hashEmbeddingSource(noteText);
            const hasCurrentEmbedding = note.embeddingSourceHash === sourceHash && Array.isArray(note.embedding);

            if (!String(noteText).trim() || hasCurrentEmbedding) {
                skippedCount++;
                continue;
            }

            const preparedNote = await prepareNoteForIndexedDb(note);
            if (Array.isArray(preparedNote.embedding)) {
                await bulkPutDB(NOTE_STORE_NAME, [preparedNote], true);
                indexedCount++;
            }
        }

        showToast((_("intelligentSearchIndexingComplete") || '...').replace('{count}', indexedCount), 4000);
        return indexedCount;
    } catch (error) {
        showToast(_('intelligentSearchIndexingFailed') || '...', 5000);
        return 0;
    }
}
```

**Процес:**
1. Предварително зарежда модела (fail-fast ако не е наличен)
2. Извлича ВСИЧКИ бележки от IndexedDB
3. За всяка бележка:
   - Изчислява хеш на текста
   - Ако вече е индексирана (хеш съвпада) — пропуска
   - Ако е празна — пропуска
   - Иначе генерира embedding и записва в DB
4. Показва toast с резултата

**Проблем:** Изпълнява се **секвенциално** (`for...of` с `await`). При 1000+ бележки може да е бавно. Няма паралелизация или батч обработка.

### 8. `findRelevantNotes(userQuery)` — Самото търсене

```javascript
async function findRelevantNotes(userQuery) {
    try {
        const extractor = await getSearchExtractor();
        if (!extractor) return [];

        showToast(_('performingSemanticSearch') || '...', 2000);

        // Генерираме embedding за заявката
        const queryOutput = await extractor(userQuery, { pooling: 'mean', normalize: true });
        const queryEmbedding = Array.from(queryOutput.data);

        // Извличаме ВСИЧКИ бележки от IndexedDB
        const allNotes = await getAllFromDB(NOTE_STORE_NAME);
        if (!allNotes) return [];

        // Изчисляваме cosine similarity за всяка бележка
        const rankedNotes = allNotes.map(note => {
            const score = note.embedding ? cosineSimilarity(queryEmbedding, note.embedding) : 0;
            return { ...note, score };
        });

        // Филтрираме по праг 0.25 и сортираме
        const resultNotes = rankedNotes
            .filter(note => note.score > 0.25)
            .sort((a, b) => b.score - a.score)
            .slice(0, 15);

        return resultNotes;
    } catch (error) {
        showToast(_('semanticSearchError') || '...', 3000);
        return [];
    }
}
```

**Алгоритъм:**
1. Генерира embedding вектор за потребителската заявка
2. Зарежда **всички** бележки от IndexedDB (включително тези без embedding)
3. За всяка бележка изчислява cosine similarity
4. Филтрира с **threshold 0.25** (доста нисък — допуска слабо свързани резултати)
5. Връща топ **15** резултата

### 9. `cosineSimilarity(vecA, vecB)` — Мярка за сходство

```javascript
function cosineSimilarity(vecA, vecB) {
    if (!vecA || !vecB) return 0;
    let dotProduct = 0.0;
    let normA = 0.0;
    let normB = 0.0;
    for (let i = 0; i < vecA.length; i++) {
        dotProduct += vecA[i] * vecB[i];
        normA += vecA[i] * vecA[i];
        normB += vecB[i] * vecB[i];
    }
    if (normA === 0 || normB === 0) return 0;
    return dotProduct / (Math.sqrt(normA) * Math.sqrt(normB));
}
```

Стандартна имплементация на cosine similarity. Връща стойност между -1 и 1, където 1 = идентични вектори.

```javascript
async function bulkPutDB(storeName, data, incremental = false) {
    // ...
    if (storeName !== NOTE_STORE_NAME || !incremental || !item?.gdid || item.embedding) {
        store.put(item);
        return;
    }

    // Запазва съществуващ embedding ако текстът не се е променил
    const existingRequest = store.get(item.gdid);
    existingRequest.onsuccess = () => {
        const existing = existingRequest.result;
        const incomingHash = hashEmbeddingSource(item.notetxt || item.text || '');
        if (existing?.embeddingSourceHash === incomingHash && Array.isArray(existing.embedding)) {
            store.put({
                ...item,
                embedding: existing.embedding,
                embeddingSourceHash: existing.embeddingSourceHash
            });
        } else {
            store.put(item);
        }
    };
}
```

**Критична оптимизация:** При синхронизация от GDrive/Local, ако текстът не се е променил (по хеш), съществуващият embedding се запазва. Това предотвратява загубата на индекси при всяка синхронизация.

## Предложена оптимизация

```javascript
async function indexNotesForIntelligentSearch() {
    if (!isIntelligentSearchEnabled()) return 0;

    try {
        // 1. Зареждаме модела ВЕДНЪЖ преди всичко (fail-fast)
        const extractor = await getIntelligentSearchExtractor();
        if (!extractor) {
            showToast(_('intelligentSearchIndexingFailed') || 'Model loading failed.', 5000);
            return 0;
        }

        const notes = await getAllFromDB(NOTE_STORE_NAME);
        if (!notes || notes.length === 0) return 0;

        // 2. Филтрираме бележките, които НАИСТИНА се нуждаят от индексиране
        const notesToIndex = notes.filter(note => {
            const noteText = note.notetxt || note.text || '';
            if (!String(noteText).trim()) return false;
            const sourceHash = hashEmbeddingSource(noteText);
            return !(note.embeddingSourceHash === sourceHash && Array.isArray(note.embedding));
        });

        const totalToIndex = notesToIndex.length;
        const alreadyIndexed = notes.length - totalToIndex;

        if (totalToIndex === 0) {
            showToast((_('intelligentSearchAlreadyIndexed') || 'All {count} notes already indexed.').replace('{count}', alreadyIndexed), 4000);
            return 0;
        }

        console.log(`[IntelligentSearch] Starting: ${totalToIndex} to index, ${alreadyIndexed} already done.`);

        // 3. Batch обработка с yield към UI
        const BATCH_SIZE = 10; // Брой бележки на батч
        const WRITE_BATCH_SIZE = 20; // Натрупваме записи преди запис в DB
        let indexedCount = 0;
        let errorCount = 0;
        let writeBuffer = [];
        let isCancelled = false;

        // 4. Показваме прогрес в loader-а
        const loaderContainer = document.getElementById('loader-container');
        const loaderText = document.getElementById('loader-text');
        const loaderTitle = document.getElementById('loader-title');
        const cancelBtn = document.getElementById('cancel-load-btn');
        
        if (loaderContainer) loaderContainer.style.display = 'block';
        if (loaderTitle) loaderTitle.textContent = _('intelligentSearchIndexingTitle') || 'Indexing notes...';

        // Слушател за прекъсване
        const cancelHandler = () => { isCancelled = true; };
        if (cancelBtn) cancelBtn.addEventListener('click', cancelHandler);

        const startTime = performance.now();

        for (let i = 0; i < totalToIndex; i += BATCH_SIZE) {
            // Проверка за прекъсване
            if (isCancelled) {
                console.log(`[IntelligentSearch] Cancelled by user at ${indexedCount}/${totalToIndex}`);
                break;
            }

            const batch = notesToIndex.slice(i, i + BATCH_SIZE);

            // 5. Обработваме батча паралелно (в рамките на BATCH_SIZE)
            const results = await Promise.allSettled(
                batch.map(async (note) => {
                    const noteText = note.notetxt || note.text || '';
                    const sourceHash = hashEmbeddingSource(noteText);

                    try {
                        const output = await extractor(noteText, { pooling: 'mean', normalize: true });
                        return {
                            ...note,
                            embedding: Array.from(output.data),
                            embeddingSourceHash: sourceHash
                        };
                    } catch (e) {
                        console.warn(`[IntelligentSearch] Failed for note ${note.gdid || note.id}:`, e.message);
                        return null;
                    }
                })
            );

            // 6. Събираме успешните резултати в буфер за запис
            for (const result of results) {
                if (result.status === 'fulfilled' && result.value) {
                    writeBuffer.push(result.value);
                    indexedCount++;
                } else if (result.status === 'rejected') {
                    errorCount++;
                }
            }

            // 7. Записваме в DB на порции (намалява I/O операциите)
            if (writeBuffer.length >= WRITE_BATCH_SIZE || i + BATCH_SIZE >= totalToIndex) {
                if (writeBuffer.length > 0) {
                    await bulkPutDB(NOTE_STORE_NAME, writeBuffer, true);
                    writeBuffer = [];
                }
            }

            // 8. Обновяваме прогреса
            const progress = Math.min(i + BATCH_SIZE, totalToIndex);
            const percent = Math.round((progress / totalToIndex) * 100);
            if (loaderText) {
                loaderText.textContent = `${progress}/${totalToIndex} (${percent}%)`;
            }

            // 9. Yield към UI — позволяваме на браузъра да прерисува
            await new Promise(resolve => setTimeout(resolve, 0));
        }

        // 10. Записваме остатъка в буфера
        if (writeBuffer.length > 0) {
            await bulkPutDB(NOTE_STORE_NAME, writeBuffer, true);
        }

        // Почистваме
        if (cancelBtn) cancelBtn.removeEventListener('click', cancelHandler);
        if (loaderContainer) loaderContainer.style.display = 'none';

        const elapsed = ((performance.now() - startTime) / 1000).toFixed(1);
        const statusMsg = isCancelled ? 'cancelled' : 'complete';
        console.log(`[IntelligentSearch] Indexing ${statusMsg}: ${indexedCount} indexed, ${errorCount} errors, ${elapsed}s`);

        const toastMsg = isCancelled
            ? (_('intelligentSearchIndexingCancelled') || 'Indexing cancelled: {count} notes indexed.').replace('{count}', indexedCount)
            : (_('intelligentSearchIndexingComplete') || 'Indexing complete: {count} notes indexed.').replace('{count}', indexedCount);

        showToast(toastMsg, 4000);
        return indexedCount;

    } catch (error) {
        console.error('[IntelligentSearch] Critical failure:', error);
        const loaderContainer = document.getElementById('loader-container');
        if (loaderContainer) loaderContainer.style.display = 'none';
        showToast(_('intelligentSearchIndexingFailed') || 'Indexing failed.', 5000);
        return 0;
    }
}
```

## Какво се подобри

| Аспект | Преди | След |
|--------|-------|------|
| **Обработка** | 1 по 1 (секвенциално) | Батчове по 10 (паралелно в рамките на батч) |
| **Запис в DB** | След всяка бележка | Натрупване по 20, после един запис |
| **UI отзивчивост** | Блокира | `setTimeout(0)` между батчове |
| **Прогрес** | Само toast в края | Жива индикация: `125/500 (25%)` |
| **Прекъсване** | Невъзможно | Бутон Cancel |
| **Филтриране** | В цикъла | Предварително (избягва излишни итерации) |
| **Грешки** | Спира при първата | `Promise.allSettled` — продължава |
| **Памет** | Цял масив в паметта | `writeBuffer` се изпразва периодично |

```javascript
    const dbNote = { ...note };
    if (!isIntelligentSearchEnabled()) return dbNote; // ← Ако е изключено, пропуска

    const noteText = dbNote.notetxt || dbNote.text || '';
    const sourceHash = hashEmbeddingSource(noteText);
    
    if (!String(noteText).trim()) {
        delete dbNote.embedding;
        delete dbNote.embeddingSourceHash;
        return dbNote;
    }
    
    // Ако хешът съвпада — пропуска (текстът не е променен)

        return dbNote;
    }

        const extractor = await getIntelligentSearchExtractor();
        if (!extractor) return dbNote;
        const output = await extractor(noteText, { pooling: 'mean', normalize: true });
        dbNote.embedding = Array.from(output.data);
        dbNote.embeddingSourceHash = sourceHash;
    } catch (error) {
        console.warn('[IntelligentSearch] Failed to generate note embedding:', error);
    }

}
```

## Решение 1: Cursor-базирано поточно обхождане (Streaming)

Вместо `getAll()`, обхождаме записите един по един с IndexedDB cursor. Така в паметта е само **една бележка** в даден момент.

```javascript
async function findRelevantNotes(userQuery) {
    try {
        const extractor = await getIntelligentSearchExtractor(true);
        if (!extractor) return [];

        showToast(_('performingSemanticSearch') || 'Searching...', 2000);

        // Генерираме embedding за заявката
        const queryOutput = await extractor(userQuery, { pooling: 'mean', normalize: true });
        const queryEmbedding = Array.from(queryOutput.data);

        // Поточно обхождане с cursor — НЕ зареждаме всичко наведнъж
        const results = await scanNotesWithCursor(queryEmbedding, 0.3, 15);

        console.log(`[Semantic] Found ${results.length} results (streaming mode)`);
        return results;
    } catch (error) {
        console.error('[Semantic] Search error:', error);
        showToast(_('semanticSearchError') || 'Search failed', 3000);
        return [];
    }
}

/**
 * Обхожда IndexedDB с cursor и изчислява similarity поточно.
 * В паметта се държат само топ N резултата.
 * 
 * @param {number[]} queryEmbedding - Векторът на заявката
 * @param {number} threshold - Минимален score за включване
 * @param {number} maxResults - Максимален брой резултати
 * @returns {Promise<Array>} Топ N бележки сортирани по score
 */
async function scanNotesWithCursor(queryEmbedding, threshold, maxResults) {
    const db = await openNotesDB();

    return new Promise((resolve, reject) => {
        const transaction = db.transaction(NOTE_STORE_NAME, 'readonly');
        const store = transaction.objectStore(NOTE_STORE_NAME);
        const request = store.openCursor();

        // Min-heap подход: пазим само топ maxResults
        const topResults = []; // Сортиран масив (по score ascending — най-ниският е първи)
        let scannedCount = 0;
        let withEmbeddingCount = 0;

        request.onsuccess = (event) => {
            const cursor = event.target.result;

            if (cursor) {
                scannedCount++;
                const note = cursor.value;

                // Пропускаме бележки без embedding или изтрити
                if (note.embedding && Array.isArray(note.embedding) && note.status !== 1) {
                    withEmbeddingCount++;
                    const score = cosineSimilarity(queryEmbedding, note.embedding);

                    if (score > threshold) {
                        // Вмъкваме в сортирания масив
                        if (topResults.length < maxResults) {
                            topResults.push({ score, note: stripEmbedding(note) });
                            topResults.sort((a, b) => a.score - b.score); // ascending
                        } else if (score > topResults[0].score) {
                            // Заменяме най-ниския score
                            topResults[0] = { score, note: stripEmbedding(note) };
                            topResults.sort((a, b) => a.score - b.score);
                        }
                    }
                }

                cursor.continue(); // Следващ запис
            } else {
                // Cursor приключи
                db.close();
                console.log(`[Semantic-Cursor] Scanned: ${scannedCount}, with embeddings: ${withEmbeddingCount}, results: ${topResults.length}`);

                // Връщаме сортирани по score descending
                const finalResults = topResults
                    .sort((a, b) => b.score - a.score)
                    .map(r => ({ ...r.note, score: r.score }));

                resolve(finalResults);
            }
        };

        request.onerror = (event) => {
            db.close();
            reject('Cursor error: ' + event.target.error);
        };

        transaction.onerror = () => {
            db.close();
            reject('Transaction error');
        };
    });
}

/**
 * Премахва тежкото embedding поле от обекта преди да го пазим в резултатите.
 * Така в topResults[] пазим само леки обекти.
 */
function stripEmbedding(note) {
    const { embedding, embeddingSourceHash, ...light } = note;
    return light;
}
```

## Сравнение на паметта

| Подход | Памет при 10K бележки | Памет при 50K бележки |
|--------|----------------------|----------------------|
| **Текущ** (`getAll`) | ~30-50MB | ~150-250MB |
| **Cursor** (ново) | ~0.5MB (15 резултата × ~3KB) | ~0.5MB (същото) |

## Как работи

```
IndexedDB Store (на диска)
    ↓
[Cursor] → чете бележка #1 → изчислява score → пази/изхвърля → освобождава RAM
    ↓
[Cursor] → чете бележка #2 → изчислява score → пази/изхвърля → освобождава RAM
    ↓
... (повтаря за всички записи)
    ↓
[Край] → връща само топ 15 резултата (без embedding полета!)
```

Cursor подходът е **най-прагматичното решение** — не изисква промяна на DB структурата, не изисква миграция, и намалява консумацията на памет от **~30MB** до **~0.5MB** при 10K бележки.

## Теоретичен анализ

| Операция | `getAll()` | Cursor |
|----------|-----------|--------|
| **Четене от диска** | Един bulk read (оптимизиран от браузъра) | Множество последователни reads |
| **Десериализация** | Всички наведнъж (V8 оптимизира batch) | По една бележка (overhead на всяка итерация) |
| **Cosine similarity** | Идентично | Идентично |
| **GC натоварване** | Голямо (освобождава 30MB+ накрая) | Минимално (освобождава по ~3KB) |

## Реални очаквания по бенчмарк

| Брой бележки | `getAll()` + filter | Cursor | Разлика |
|--------------|--------------------:|-------:|--------:|
| 1,000 | ~80ms | ~120ms | +50% |
| 5,000 | ~300ms | ~500ms | +65% |
| 10,000 | ~600ms | ~1000ms | +65% |
| 50,000 | ~3s (ако не крашне) | ~5s | +65% |

**Cursor е ~50-70% по-бавен**, но:
- При `getAll()` на 50K бележки браузърът може да **крашне** от OOM
- Cursor **винаги** работи, независимо от размера на данните

## Защо е по-бавно

```
getAll():
  [DB Engine] → bulk read → [един JS масив] → iterate в JS (бързо)
  
Cursor:
  [DB Engine] → read 1 → [JS callback] → read 2 → [JS callback] → ...
  ↑ Всяко continue() е нов IPC цикъл между JS и IndexedDB engine
```

Основният overhead е **IPC (Inter-Process Communication)** — всяко `cursor.continue()` е отделна заявка към storage engine-а.

## Хибридно решение (Най-добър компромис)

Идеята: Зареждаме **само embedding полетата** с проекция, без пълното съдържание на бележките. След като намерим топ резултати, зареждаме пълните данни само за тях.

## Финално решение: Batch Cursor (Chunk-базиран)

Четем по **порции от 200-500 записа** наведнъж — баланс между скорост и памет:

```javascript
async function findRelevantNotes(userQuery) {
    try {
        const extractor = await getIntelligentSearchExtractor(true);
        if (!extractor) return [];

        showToast(_('performingSemanticSearch') || 'Searching...', 2000);

        const queryOutput = await extractor(userQuery, { pooling: 'mean', normalize: true });
        const queryEmbedding = Array.from(queryOutput.data);

        const topResults = await batchScanForSimilarity(queryEmbedding, 0.3, 15);

        console.log(`[Semantic] Found ${topResults.length} results (batch mode)`);
        return topResults;
    } catch (error) {
        console.error('[Semantic] Search error:', error);
        showToast(_('semanticSearchError') || 'Search failed', 3000);
        return [];
    }
}

/**
 * Обхожда IndexedDB на порции (chunks), изчислява similarity,
 * и пази само топ N резултати. Баланс между скорост и памет.
 */
async function batchScanForSimilarity(queryEmbedding, threshold, maxResults) {
    const CHUNK_SIZE = 300; // Оптимален размер: достатъчно за бърз bulk read, не е твърде много за RAM
    const db = await openNotesDB();

    return new Promise((resolve, reject) => {
        const transaction = db.transaction(NOTE_STORE_NAME, 'readonly');
        const store = transaction.objectStore(NOTE_STORE_NAME);

        // Използваме cursor с advance за chunk-базирано четене
        const topResults = []; // [{score, noteLight}] — сортиран ascending по score
        let minScoreInResults = 0; // Кеширан минимален score за бързо отхвърляне
        let processedCount = 0;
        let chunkBuffer = [];

        const request = store.openCursor();

        request.onsuccess = (event) => {
            const cursor = event.target.result;

            if (cursor) {
                chunkBuffer.push(cursor.value);

                if (chunkBuffer.length >= CHUNK_SIZE) {
                    // Обработваме натрупания chunk
                    processChunk(chunkBuffer, queryEmbedding, threshold, maxResults, topResults);
                    minScoreInResults = topResults.length >= maxResults ? topResults[0].score : 0;
                    processedCount += chunkBuffer.length;
                    chunkBuffer = []; // Освобождаваме паметта
                }

                cursor.continue();
            } else {
                // Последен непълен chunk
                if (chunkBuffer.length > 0) {
                    processChunk(chunkBuffer, queryEmbedding, threshold, maxResults, topResults);
                    processedCount += chunkBuffer.length;
                    chunkBuffer = null; // Освобождаваме
                }

                db.close();
                console.log(`[Semantic-Batch] Processed: ${processedCount}, results: ${topResults.length}`);

                // Финални резултати — сортирани descending, с пълни данни от паметта
                const finalResults = topResults
                    .sort((a, b) => b.score - a.score)
                    .map(r => {
                        const fullNote = allNotesData.find(n =>
                            (n.gdid && n.gdid === r.gdid) || (n.id && String(n.id) === String(r.id))
                        );
                        return fullNote ? { ...fullNote, score: r.score } : { ...r, score: r.score };
                    })
                    .filter(Boolean);

                resolve(finalResults);
            }
        };

        request.onerror = (event) => { db.close(); reject(event.target.error); };
        transaction.onerror = () => { db.close(); reject('Transaction error'); };
    });
}

/**
 * Обработва един chunk от бележки — изчислява similarity и поддържа топ N.
 */
function processChunk(chunk, queryEmbedding, threshold, maxResults, topResults) {
    for (let i = 0; i < chunk.length; i++) {
        const note = chunk[i];

        // Бърз skip — без embedding или изтрита
        if (!note.embedding || note.status === 1) continue;

        const score = cosineSimilarity(queryEmbedding, note.embedding);

        // Бърз skip — под прага или под минималния score в резултатите
        if (score <= threshold) continue;
        if (topResults.length >= maxResults && score <= topResults[0].score) continue;

        // Пазим само леки данни (без embedding!)
        const lightNote = { gdid: note.gdid, id: note.id, score };

        if (topResults.length < maxResults) {
            topResults.push(lightNote);
            topResults.sort((a, b) => a.score - b.score); // ascending — [0] е най-ниският
        } else {
            // Заменяме най-ниския
            topResults[0] = lightNote;
            topResults.sort((a, b) => a.score - b.score);
        }
    }
}
```

## Допълнителна микрооптимизация на `cosineSimilarity`

Тъй като embeddings са **нормализирани** (от `normalize: true`), cosine similarity се свежда до **dot product**:

```javascript
function cosineSimilarityNormalized(vecA, vecB) {
    // За нормализирани вектори: cos(a,b) = dot(a,b)
    // Спестяваме 2× sqrt + 2× norm изчисления
    if (!vecA || !vecB) return 0;
    let dot = 0;
    for (let i = 0; i < vecA.length; i++) {
        dot += vecA[i] * vecB[i];
    }
    return dot;
}
```

Това е **~3× по-бързо** от пълната cosine формула, защото пропускаме изчислението на нормите (те са винаги 1.0 за нормализирани вектори).
User: но нали всички бележки ни трябват в паметта за други операции - филтриране по бордове, другите видове търсене ...
Model: # Правилно наблюдение!

Да, `allNotesData` **вече е в паметта** за целия живот на приложението. Тогава зареждането от IndexedDB в `findRelevantNotes` е **излишен дубъл**.

## Истинският проблем

```javascript
// НО — в момента allNotesData НЕ съдържа embeddings!
```

Нека проверим кога се попълва `allNotesData`:

```javascript

```

## Ситуации

| Режим | `allNotesData` съдържа embeddings? |
|-------|-----------------------------------|
| Зареждане от IndexedDB (`fetchAllDataLocal`) | ✅ Да |
| Зареждане от GDrive (`fetchAllData`) | ❌ Не |
| След background sync | ❌ Не (синхронизираните обекти идват от GDrive) |
| След `saveEditedNote` с IS включено | ❌ Не (записва се в DB фоново, но `noteObj` в паметта няма embedding) |

## Коректното решение

Тъй като `allNotesData` **вече е в паметта**, трябва просто да го използваме директно — **без повторно четене от DB**. Но трябва да гарантираме, че embeddings са налични в паметта.

### Подход: Lean memory + DB lookup само за embeddings

```javascript
async function findRelevantNotes(userQuery) {
    try {
        const extractor = await getIntelligentSearchExtractor(true);
        if (!extractor) return [];

        showToast(_('performingSemanticSearch') || 'Searching...', 2000);

        const queryOutput = await extractor(userQuery, { pooling: 'mean', normalize: true });
        const queryEmbedding = Array.from(queryOutput.data);

        // Проверяваме дали allNotesData съдържа embeddings
        const hasEmbeddingsInMemory = allNotesData.some(n => Array.isArray(n.embedding));

        let results;
        if (hasEmbeddingsInMemory) {
            // БЪРЗ ПЪТ: Embeddings са вече в паметта — директно сканираме
            results = searchInMemory(queryEmbedding, 0.3, 15);
        } else {
            // БАВЕН ПЪТ: Embeddings са само в DB — четем ги поточно
            results = await searchWithCursorEmbeddingsOnly(queryEmbedding, 0.3, 15);
        }

        console.log(`[Semantic] Found ${results.length} results (memory: ${hasEmbeddingsInMemory})`);
        return results;
    } catch (error) {
        console.error('[Semantic] Search error:', error);
        showToast(_('semanticSearchError') || 'Search failed', 3000);
        return [];
    }
}

/**
 * Бърз път: Търси директно в allNotesData (embeddings вече са в RAM).
 * Няма допълнително I/O.
 */
function searchInMemory(queryEmbedding, threshold, maxResults) {
    const scored = [];

    for (let i = 0; i < allNotesData.length; i++) {
        const note = allNotesData[i];
        if (!note.embedding || note.status === 1) continue;

        // За нормализирани вектори: cosine = dot product
        let dot = 0;
        const emb = note.embedding;
        for (let j = 0; j < queryEmbedding.length; j++) {
            dot += queryEmbedding[j] * emb[j];
        }

        if (dot > threshold) {
            scored.push({ ...note, score: dot });
        }
    }

    scored.sort((a, b) => b.score - a.score);
    return scored.slice(0, maxResults);
}

/**
 * Бавен път: Когато allNotesData НЕ съдържа embeddings.
 * Чете САМО embedding полетата от DB чрез cursor,
 * и връща пълните обекти от allNotesData.
 */
async function searchWithCursorEmbeddingsOnly(queryEmbedding, threshold, maxResults) {
    const db = await openNotesDB();

    return new Promise((resolve, reject) => {
        const transaction = db.transaction(NOTE_STORE_NAME, 'readonly');
        const store = transaction.objectStore(NOTE_STORE_NAME);
        const request = store.openCursor();

        const topResults = []; // [{gdid, id, score}]

        request.onsuccess = (event) => {
            const cursor = event.target.result;

            if (cursor) {
                const record = cursor.value;

                if (record.embedding && record.status !== 1) {
                    let dot = 0;
                    const emb = record.embedding;
                    for (let j = 0; j < queryEmbedding.length; j++) {
                        dot += queryEmbedding[j] * emb[j];
                    }

                    if (dot > threshold) {
                        if (topResults.length < maxResults) {
                            topResults.push({ gdid: record.gdid, id: record.id, score: dot });
                            topResults.sort((a, b) => a.score - b.score);
                        } else if (dot > topResults[0].score) {
                            topResults[0] = { gdid: record.gdid, id: record.id, score: dot };
                            topResults.sort((a, b) => a.score - b.score);
                        }
                    }
                }

                cursor.continue();
            } else {
                db.close();

                // Маппваме обратно към пълните обекти от паметта
                const finalResults = topResults
                    .sort((a, b) => b.score - a.score)
                    .map(r => {
                        const fullNote = allNotesData.find(n =>
                            (n.gdid && n.gdid === r.gdid) || (String(n.id) === String(r.id))
                        );
                        return fullNote ? { ...fullNote, score: r.score } : null;
                    })
                    .filter(Boolean);

                resolve(finalResults);
            }
        };

        request.onerror = (event) => { db.close(); reject(event.target.error); };
        transaction.onerror = () => { db.close(); reject('Transaction error'); };
    });
}
```

```javascript
/**
 * Дозарежда embedding полетата от IndexedDB в allNotesData.
 * Изпълнява се фоново, не блокира UI.
 */
async function enrichAllNotesWithEmbeddings() {
    const notesWithoutEmbedding = allNotesData.filter(n => !n.embedding);
    if (notesWithoutEmbedding.length === 0) return;

    console.log(`[IS] Enriching ${notesWithoutEmbedding.length} notes with embeddings from DB...`);
    let enrichedCount = 0;

    const db = await openNotesDB();
    const transaction = db.transaction(NOTE_STORE_NAME, 'readonly');
    const store = transaction.objectStore(NOTE_STORE_NAME);

    for (const note of notesWithoutEmbedding) {
        const key = note.gdid || note.id;
        if (!key) continue;

        try {
            const dbRecord = await new Promise((resolve, reject) => {
                const req = store.get(key);
                req.onsuccess = () => resolve(req.result);
                req.onerror = () => resolve(null);
            });

            if (dbRecord && dbRecord.embedding) {
                note.embedding = dbRecord.embedding;
                note.embeddingSourceHash = dbRecord.embeddingSourceHash;
                enrichedCount++;
            }
        } catch (e) { /* ignore individual failures */ }
    }

    db.close();
    console.log(`[IS] Enriched ${enrichedCount} notes with embeddings.`);
}
```

Ако **15MB** допълнително за embeddings е проблем (мобилни устройства), можем да ги **не** зареждаме в `allNotesData` и винаги да ползваме cursor подхода. Но на практика:

- Модерен телефон има 3-6GB RAM
- Браузърът обикновено разполага с 200-500MB за tab

**15MB е приемливо** за повечето устройства. Ако е проблем — ползваме cursor варианта винаги.

Просто добавяме обратно синхронизиране в `allNotesData`:

```javascript
        if (enrichedNote.embedding) {
            // 1. Записваме в DB
            bulkPutDB(NOTE_STORE_NAME, [enrichedNote], true);

                memNote.embedding = enrichedNote.embedding;
                memNote.embeddingSourceHash = enrichedNote.embeddingSourceHash;

    }).catch(e => console.warn('[IS] Background embedding failed:', e));
```

```javascript
if (isNote) {
    dataToPut.forEach(newNote => {

        if (mIdx !== -1) {
```

### 3. Функцията `enrichAllNotesWithEmbeddings`

```javascript
/**
 * Дозарежда embedding полетата от IndexedDB в allNotesData за бележки,
 * които нямат embedding в паметта, но може да имат в DB.
 * Изпълнява се фоново, не блокира UI.
 */
async function enrichAllNotesWithEmbeddings() {
    if (!isIntelligentSearchEnabled()) return;

    const notesNeedingEmbedding = allNotesData.filter(n =>
        !n.embedding && (n.notetxt || n.text || '').trim() !== ''
    );

    if (notesNeedingEmbedding.length === 0) return;

    console.log(`[IS-Enrich] Loading embeddings for ${notesNeedingEmbedding.length} notes from DB...`);

    let enrichedCount = 0;
    const db = await openNotesDB();

    try {
        const transaction = db.transaction(NOTE_STORE_NAME, 'readonly');
        const store = transaction.objectStore(NOTE_STORE_NAME);

        // Batch get — по-ефективно от cursor когато знаем точно кои ключове търсим
        const getPromises = notesNeedingEmbedding.map(note => {
            const key = note.gdid || note.id;
            if (!key) return Promise.resolve(null);

            return new Promise(resolve => {
                const req = store.get(key);
                req.onsuccess = () => resolve({ note, dbRecord: req.result });
                req.onerror = () => resolve(null);
            });
        });

        const results = await Promise.all(getPromises);

        for (const result of results) {
            if (!result || !result.dbRecord) continue;
            const { note, dbRecord } = result;

            if (dbRecord.embedding && Array.isArray(dbRecord.embedding)) {
                // Допълнителна проверка: embedding-ът валиден ли е за текущия текст?
                const currentHash = hashEmbeddingSource(note.notetxt || note.text || '');
                if (dbRecord.embeddingSourceHash === currentHash) {
                    note.embedding = dbRecord.embedding;
                    note.embeddingSourceHash = dbRecord.embeddingSourceHash;
                    enrichedCount++;
                }
            }
        }

        await new Promise((resolve, reject) => {
            transaction.oncomplete = () => resolve();
            transaction.onerror = () => reject(transaction.error);
        });
    } catch (e) {
        console.warn('[IS-Enrich] Error during enrichment:', e);
    } finally {
        db.close();
    }

    console.log(`[IS-Enrich] Enriched ${enrichedCount}/${notesNeedingEmbedding.length} notes.`);
}
```

| Файл/Място | Промяна |
|------------|---------|
| `runGoogleDriveSync()` → `syncFileWorker` → "Update allNotesData" | Запазва embedding ако хешът съвпада |

С тези промени embeddings ще бъдат **винаги налични** в `allNotesData`, независимо от начина на зареждане.


Когато създавате нова бележка с текст или редактирате текста - ако е включена настройката intelligent-search-checkbox бележката директно може да се индексира - да се добави embedding. Ако не е включена тази настройка е добре да се знае дали изобщо базата е индексирана, което може да се разбере при зареждане - ако бележките имат embedding, да се вдига флаг, както и при индексиране след вклюване на настройката. в този случай не би трябвало да има бележки, които не са индексирани при включена настройка

нека разгледаме изобщо има ли нужда от проверка и от set за по-бързи операции:

настройката intelligent search е изключена - всичко работи без никакви embedding-и
включваме intelligent search - ЦЯЛАТА база се индексира, новите и променени бележки се индексират при запис
настройката intelligent search е включена, но се зарежда база без embedding в записите - ЦЯЛАТА база ТРЯБВА да се индексира и минаваме към случай 2. Така че ако реализираме т. 3 би трябвало да не съществуват неиндексирани бележки и няма нужда да проверяваме. Провери, но мисля, че сега при включена настройка новите и променени бележки се индексират.
