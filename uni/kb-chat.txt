🎯 Възможни Подходи
1. Локален AI Асистент (Offline)
Как работи:

Използва малък language model, който работи директно в браузъра (напр. Web LLM, TensorFlow.js)
Всички данни остават на устройството на потребителя
Предимства:

✅ Пълна поверителност
✅ Работи без интернет
✅ Без разходи за API
Недостатъци:

❌ Ограничени възможности на модела
❌ Бавна първоначална зареждане (модели 50-500MB)
❌ Изисква мощно устройство
Генериране на знание:

Трябва да подготвиш ръчно документация/FAQ
Моделът ще използва този контекст за отговори
2. Cloud AI API (Online)
Как работи:

Интеграция с OpenAI, Anthropic Claude, Google Gemini и др.
Заявки се изпращат към външен API
Предимства:

✅ Много по-интелигентни отговори
✅ Бързо зареждане
✅ Работи на всяко устройство
Недостатъци:

❌ Изисква API ключ (разходи)
❌ Нужна интернет връзка
❌ Данните се изпращат към трета страна
Генериране на знание:

Автоматично: Можеш да извлечеш информация от HTML/JS файловете
Полу-автоматично: Скрипт, който анализира настройките и генерира описания
Ръчно: Създаваш структуриран документ с инструкции
3. Хибриден Подход (Препоръчвам)
Как работи:

Базова помощ с предварително дефинирани отговори (pattern matching)
Опция за "умен режим" с API при нужда
Предимства:

✅ Бързи отговори за чести въпроси
✅ AI само когато е нужно
✅ Контрол над разходите
Недостатъци:

❌ По-сложна имплементация

2. Интелигентен Matcher
Алгоритъм за намиране на най-добрия отговор:

javascript
class AssistantMatcher {
  constructor(kb, language) {
    this.kb = kb;
    this.lang = language;
  }
  
  findAnswer(userQuery) {
    const query = userQuery.toLowerCase();
    const words = query.split(/\s+/);
    
    // 1. Търси в настройки и общи въпроси
    const allEntries = [...this.kb.settings, ...this.kb.general];
    
    // 2. Scoring система
    const scored = allEntries.map(entry => {
      let score = 0;
      const keywords = entry.keywords[this.lang] || [];
      
      // Точно съвпадение на ключова дума
      keywords.forEach(keyword => {
        if (query.includes(keyword)) {
          score += 10;
        }
      });
      
      // Частично съвпадение
      words.forEach(word => {
        keywords.forEach(keyword => {
          if (keyword.includes(word) || word.includes(keyword)) {
            score += 3;
          }
        });
      });
      
      return { entry, score };
    });
    
    // 3. Сортира по score
    scored.sort((a, b) => b.score - a.score);
    
    // 4. Връща топ 3 резултата
    return scored.slice(0, 3).filter(s => s.score > 0);
  }
}

Ако Искаш Множество Въпроси за Една Настройка
Ако една настройка може да отговори на няколко различни въпроса, има два подхода:

Подход 1: Включи всичко в отговора (Препоръчвам)
json

# Функция за компактно форматиране на keywords
function Format-Keywords {
    param($obj)
    
    if ($obj -is [System.Collections.ArrayList] -or $obj -is [Array]) {
        return $obj
    }
    
    if ($obj -is [PSCustomObject]) {
        $obj.PSObject.Properties | ForEach-Object {
            if ($_.Name -eq 'keywords' -and $_.Value -is [PSCustomObject]) {
                # Запазваме keywords като са
            } elseif ($_.Value -is [PSCustomObject] -or $_.Value -is [System.Collections.ArrayList] -or $_.Value -is [Array]) {
                Format-Keywords $_.Value
            }
        }
    }
    
    return $obj
}

# Конвертираме обратно в JSON с компактни keywords
$jsonText = $json | ConvertTo-Json -Depth 20

# Заместваме многоредовите keywords масиви с едноредови
$jsonText = $jsonText -replace '(?s)"keywords":\s*\{\s*"bg":\s*\[\s*(.*?)\s*\],\s*"en":\s*\[\s*(.*?)\s*\]', {
    param($match)
    $bg = $match.Groups[1].Value -replace '\s+', ' ' -replace '",\s*"', '", "'
    $en = $match.Groups[2].Value -replace '\s+', ' ' -replace '",\s*"', '", "'
    '"keywords": { "bg": [' + $bg + '], "en": [' + $en + ']'
}

Нови Функции:
1. showKBAnswer(kbEntry, mode = 'static')
javascript
/**
 * Показва Mr. StickyMan с отговор от KB
 * @param {Object} kbEntry - KB запис с guide данни
 * @param {String} mode - 'static' (не се движи) или 'guided' (като tour)
 */
function showKBAnswer(kbEntry, mode = 'static') {
  if (!kbEntry.guide) {
    // Fallback: показва само текста без позициониране
    showSimpleAnswer(kbEntry.answer);
    return;
  }
  
  // Конвертираме KB entry в step формат
  const step = {
    image: kbEntry.guide.image,
    height: kbEntry.guide.height,
    target: kbEntry.guide.target,
    textKey: kbEntry.answer[currentLang],  // Директно текста
    x: kbEntry.guide.x,
    y: kbEntry.guide.y,
    bx: kbEntry.guide.bx,
    by: kbEntry.guide.by,
    bWidth: kbEntry.guide.bWidth,
    bHeight: kbEntry.guide.bHeight
  };
  
  // Използваме съществуващата showStep функция
  showStep(step, null, true);  // single = true (не преминава към следваща)
  
  // Опционално: highlight на target елемента
  if (kbEntry.guide.action === 'highlight') {
    highlightElement(kbEntry.guide.target);
  }
}

1. showKBAnswer(kbEntry, options = {})
javascript
/**
 * Показва Mr. StickyMan с отговор от KB
 * @param {Object} kbEntry - KB запис с guide данни
 * @param {Object} options - Опции за показване
 */
function showKBAnswer(kbEntry, options = {}) {
  const {
    mode = 'static',        // 'static' или 'guided'
    highlight = true,       // Highlight на target
    autoClose = false,      // Автоматично затваряне
    duration = 15000        // Време за autoClose
  } = options;
  
  if (!kbEntry.guide) {
    // Fallback: показва текста в обикновен toast
    showToast(kbEntry.answer[currentLang], 5000);
    return;
  }
  
  // Конвертираме KB entry в step формат
  const step = {
    image: kbEntry.guide.image,
    height: kbEntry.guide.height,
    target: kbEntry.guide.target,
    textKey: kbEntry.answer[currentLang],  // Директен текст
    x: kbEntry.guide.x,
    y: kbEntry.guide.y,
    bx: kbEntry.guide.bx,
    by: kbEntry.guide.by,
    bWidth: kbEntry.guide.bWidth,
    bHeight: kbEntry.guide.bHeight
  };
  
  // Добавяме ! ако е stopAfter
  if (kbEntry.guide.stopAfter) {
    step.image += '!';
  }
  
  // Показваме героя
  showStep(step, null, true);  // single = true
  
  // Highlight на елемента
  if (highlight && kbEntry.guide.action === 'highlight') {
    highlightElement(kbEntry.guide.target);
  }
  
  // Auto-close
  if (autoClose) {
    setTimeout(() => {
      if (container) container.remove();
    }, duration);
  }
}

/**
 * Показва mini-tour от конкретни стъпки
 * @param {Array} stepIndices - Масив от индекси на стъпки
 */
function showMiniTour(stepIndices) {
  if (!stepIndices || stepIndices.length === 0) return;
  
  // Създаваме временен steps масив
  const miniSteps = stepIndices.map(i => steps[i]);
  
  // Запазваме оригиналния steps
  const originalSteps = window.steps;
  
  // Заместваме временно
  window.steps = miniSteps;
  
  // Показваме първата стъпка
  showStep(0);
  
  // Възстановяваме оригиналния steps след края
  // (това ще се случи автоматично когато tour-ът приключи)
}
3. showContextualTips(context)
javascript
/**
 * Показва контекстни съвети според текущото състояние
 * @param {String} context - 'settings', 'calendar', 'boards', etc.
 */
function showContextualTips(context) {
  // Намира релевантни KB записи
  const contextEntries = kbData.settings.filter(
    entry => entry.guide && entry.guide.context === context
  );
  
  if (contextEntries.length === 0) return;
  
  // Избира случаен съвет
  const randomTip = contextEntries[
    Math.floor(Math.random() * contextEntries.length)
  ];
  
  // Показва героя с подсказка
  showKBAnswer(randomTip, {
    mode: 'static',
    highlight: true,
    autoClose: true,
    duration: 10000
  });
}
