User Guide

In the CX MultiNotes Viewer user guide, you will find information on how to use the application, its features, and settings.

How the Application Manages Your Data

CX MultiNotes Viewer provides fast access to your notes from any device, without installation, and with the ability to work offline. The main operating mode uses a local database in your browser, ensuring optimal performance and offline access.

Main Mode with Local Database

This mode is active by default and offers the best combination of speed, efficiency, and independence from an internet connection.

  • On first launch, the application downloads all notes from Google Drive and saves them to a local database.
  • Every subsequent load is done directly from this database, with a check performed to download only the files that have changed since the last synchronization, which is extremely fast.
  • If you uncheck Google Drive in Settings, you can work without an internet connection, but no check for new and changed notes will be performed. In this case, it is useful to periodically re-enable the option to update your data.

Mode without Database

  • If you uncheck Database in Settings, the notes are loaded directly from Google Drive on every launch.
  • The most up-to-date data is always displayed.
  • Slower loading and requires an internet connection.

Additional Modes (Advanced Settings)

Through the Advanced Settings menu, you can activate alternative operating modes suitable for specific cases. These modes can work with or without using a local database, depending on your preferences.

Local Folder

  • Data is read from a folder on your computer. You need to configure the Google Drive for Desktop application to synchronize multinotes_data from Google Drive to your computer (you can also set the data to be available offline) and specify the synchronized folder in Settings -> Advanced Settings.
  • If you use this mode and check the Database option, on every launch, a check will be performed, and only new and edited notes will be loaded to supplement the ones saved in the database.

    • Mode: Archive

    • This mode is used when you transfer a zip archive of notes created by the application with Data backup. Unzip it into a local folder and specify it in Settings -> Advanced Settings.
    • No updates are performed; only the notes from the archive are displayed.
    • Suitable for offline access to old versions of your notes.
